## 🚀 Getting Started

### Step 1: Install Unity
Download **Unity 2021.3 LTS** from https://unity.com/download

### Step 2: Open Project
1. Launch **Unity Hub**
2. Click **Add** → Select `SimpsonsPokeGame` folder
3. Wait for import to complete

### Step 3: Create Scene
Follow **SETUP_GUIDE.md** to create MainScene with:
- Player GameObject
- Ground with collider
- Wild Grass area with EncounterTrigger
- NPCs with dialogue
- Canvas with UI panels
- GameManager with all systems

### Step 4: Play!
1. Press **Play** in Unity Editor
2. Use **Arrow Keys** to move
3. Press **Space** to interact with NPCs
4. Walk through grass for encounters
