## 🚀 How to Get Started (3 Steps)

### Step 1: Install Unity
- Download Unity 2021.3 LTS (or newer)
- From: https://unity.com/download

### Step 2: Open Project
- Launch Unity Hub
- Click "Add" → Select SimpsonsPokeGame folder
- Wait for import (2-5 minutes)

### Step 3: Create Scene
- Read `SETUP_GUIDE.md` (step-by-step instructions)
- Takes ~45 minutes
- Follow hierarchy exactly as shown

### Step 4: Play!
- Press Play button in Unity
- Use Arrow Keys to move
- Press Space to interact with NPCs
- Walk through grass for encounters
